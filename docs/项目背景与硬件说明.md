# WHEELTEC B585 平衡小车课程实践背景依据

> 用途：作为 Agent 项目中的课程背景、任务边界、目标约束与验收依据。  
> 适用对象：基于 WHEELTEC B585 平衡小车的控制算法设计、模块开发、调试规划、实验报告生成与验收辅助。  
> 信息来源：课程实践说明截图整理。  
> 注意：本文档只描述课程实践背景与约束，不包含任何源代码。

---

## 1. 项目概述

本次课程实践采用 **“三层目标、弹性达成”** 的设计理念，围绕 WHEELTEC B585 平衡小车完成硬件搭建、开发环境配置、基础功能验证、姿态感知、平衡 PID 控制、系统扩展功能开发、综合测试与报告撰写。

项目的核心任务不是单一地让小车“能动”，而是完成一个可验收、可调试、可解释的平衡车控制系统：

- 底层：硬件安全搭建、开发环境配置、基础功能验证；
- 中层：电机、编码器、姿态传感器、PID 控制等核心模块独立开发与调试；
- 高层：多传感器融合、扩展功能、系统级问题排查、现场答辩与综合设计报告。

## 3. 实践目标

### 3.1 三层目标

| 目标层次 | 对应成绩 | 核心要求 |
|---|---:|---|
| 基础目标 | 及格～中等 | 完成硬件安全搭建、开发环境配置、基础功能验证；小车直立时间不少于 10 秒；掌握电驱与姿态感知基础；完成 PID 参数基础调节；提交实验报告 |
| 进阶目标 | 中等～良好 | 完成独立模块开发；对比三种姿态解算方法：DMP、卡尔曼滤波、互补滤波；完成 PID 算法独立设计与参数整定；完成系统调试优化；至少实现一项功能扩展，如蓝牙遥控或 OLED 显示 |

## 4. 知识模块

课程实践包含四个主要知识模块。Agent 在提供建议时，应围绕这些模块组织内容，而不是泛泛回答“嵌入式开发”或“机器人控制”。

| 知识模块 | 核心内容 |
|---|---|
| 电驱系统控制 | 直流减速电机与编码器工作原理；STM32 定时器 PWM 输出；编码器输入捕获；电机开环调速与闭环控制；速度环、位置环；增量式 PI 与位置式 PID |
| 姿态感知系统 | MPU6050 六轴传感器原理，包括加速度计与陀螺仪；I2C 通信配置；三种姿态解算方法，包括 DMP 内置解算、卡尔曼滤波、一阶互补滤波；滤波参数调优 |
| 平衡 PID 算法设计 | 倒立摆控制原理；级联 PID 控制结构，包括平衡环 PD、速度环 PI、转向环；PID 参数整定方法，包括试凑法与观察法；上位机或蓝牙 APP 辅助调参 |
| 系统综合应用 | 多环融合控制；系统总体架构；5 ms 中断时序；扩展功能开发，包括遥控交互、环境感知、算法进阶；系统调试与优化 |

## 6. 成绩构成

总评成绩为 100%。

| 考核项目 | 权重 | 说明 |
|---|---:|---|
| 硬件搭建 | 10% | 硬件组装完整性、接线正确性、安全意识 |

| 综合测评验收 | 50% | 现场验收，包括基础能力、扩展功能、问题分析、现场表现 |
| 实践报告 | 10% | 综合设计报告 |
| 课程思政 | 5% | 思政小论文 |

### 6.1 Agent 项目中的评分优先级

由于综合测评验收占 50%，Agent 的任务规划应优先服务于现场验收表现，而不是只服务于文档撰写。

优先级建议：

1. **小车稳定平衡时间**：这是基础验收的硬指标；
2. **扩展功能是否可演示**：决定能否从中等进入良好或优秀；
3. **问题分析能力**：现场答辩中需要解释调试过程、关键故障和解决方式；
4. **报告完整性**：报告占比不高，但必须规范提交；
5. **课程思政内容**：占比最低，但不能遗漏。

## 11. 推荐的 Agent 工作原则

### 11.1 先满足验收，再追求扩展

在实践时间有限的情况下，Agent 应优先帮助用户完成稳定平衡、基础模块调试和现场验收，再考虑 LQR、多传感器融合等拔高功能。

推荐顺序：

1. 硬件接线和烧录通过；
2. 电机方向、编码器方向确认；
3. MPU6050 姿态角稳定；
4. 平衡环 PD 能让小车短暂站立；
5. 速度环 PI 抑制前后漂移；
6. 转向环接入；
7. 完成 10 秒、30 秒、60 秒分级验收；
8. 加入一个稳定扩展功能；
9. 整理调试问题与报告材料。

### 11.2 输出内容必须可落地

Agent 的回答应尽量落到以下形式：

- 可执行步骤；
- 可检查指标；
- 参数调试方向；
- 故障现象 → 可能原因 → 排查动作；
- 报告可直接使用的结构化内容；
- 验收前可逐项勾选的清单。

### 11.3 不把复杂度提前

LQR、多传感器融合、避障、跟随、巡线属于拔高目标。只有在基础平衡功能稳定后，Agent 才应建议投入主要精力到这些方向。

## 12. 典型验收问题与准备方向

| 方向 | 可能被问的问题 | 准备要点 |
|---|---|---|
| 硬件搭建 | 主控、驱动、电机、传感器分别负责什么 | 能说明信号链路：传感器采集 → 主控计算 → PWM 输出 → 电机执行 |
| 姿态感知 | 为什么需要 MPU6050，为什么不能只用加速度计 | 能说明加速度计受振动影响，陀螺仪会漂移，因此需要融合或滤波 |
| 姿态解算 | DMP、卡尔曼滤波、互补滤波有什么区别 | 能从实现难度、计算量、抗噪能力、调参复杂度进行比较 |
| PID 控制 | 平衡环、速度环、转向环分别控制什么 | 平衡环控制角度，速度环抑制位置漂移，转向环控制左右差速 |
| 调参 | 小车抖动、前冲、倒向一边时怎么排查 | 能按姿态零偏、电机方向、编码器方向、PID 参数、机械重心逐项检查 |
| 扩展功能 | 扩展功能如何接入主系统 | 能说明扩展功能不能破坏主平衡控制时序，优先在低频任务或状态机中处理 |
| 报告 | 为什么报告不能贴源码 | 课程要求用流程图或文字描述算法，重点考查设计理解而非代码堆砌 |

## 13. 背景摘要

本课程实践的本质是：在 STM32F103RCT6 和 MPU6050 平台上，围绕两轮平衡小车完成从硬件搭建、姿态感知、电机闭环控制到级联 PID 平衡控制的完整系统实践。成绩主要由现场综合验收决定，因此 Agent 项目应将“稳定平衡时间、扩展功能演示、问题分析能力、报告规范性”作为核心约束。

最低目标是完成基础硬件和小车短暂平衡；稳妥目标是小车稳定平衡 30 秒以上并实现一个扩展功能；冲优目标是小车稳定平衡 60 秒以上、实现高质量扩展功能，并能系统性排查 3 个以上关键问题。
