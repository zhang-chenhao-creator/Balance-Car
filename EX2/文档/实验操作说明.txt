二、硬件连接
1. 主控：WHEELTEC C10B / STM32F103RCT6。
2. 串口：USART1 PA9/PA10 -> CH9102，当前电脑识别为 COM7。
3. MPU6050：PB14=SCL，PB15=SDA，PB9=INT。
4. 本固件不初始化电机 PWM，不会主动驱动电机。

三、串口参数
1. 115200 baud，8 数据位，1 停止位，无校验。
2. 命令必须以 CRLF 结尾。
3. 上电后默认开启 CSV 输出。

四、串口命令
HELP                         查看命令。
STATUS                       查看 WHO_AM_I、RAW/DMP 状态、输出频率等。
CAL                          静止校准，请保持小车不动约 1 秒。
LOG 1 / LOG 0                开启/关闭 CSV 输出。
MODE RAW                     记录原始读取观察模式。
MODE DMP                     记录 DMP 观察模式。
MODE COMP                    记录互补滤波观察模式。
MODE KALMAN                  记录卡尔曼滤波观察模式。
MODE ALL                     同时输出所有方法，默认模式。
STATE STATIC                 标记当前数据为静止状态。
STATE TILT                   标记当前数据为倾斜状态。
STATE SHAKE                  标记当前数据为快速晃动状态。
RATE 20 / RATE 50 / RATE 100 设置 CSV 输出频率。

五、CSV 字段
A,ms,state,mode,ax_raw,ay_raw,az_raw,gx_raw,gy_raw,gz_raw,ax_g,ay_g,az_g,gx_dps,gy_dps,gz_dps,pitch_acc,pitch_dmp,pitch_comp,pitch_kalman,dmp_hz,dt_ms,status

六、建议实验步骤
1. 烧录后打开串口，先观察 BOOT 行：
   BOOT,WHO_AM_I=0x68,RAW=1,DMP=1
   若 DMP=0，仍可采集原始值、互补滤波、卡尔曼滤波；检查 MPU6050 接线后重启。
2. 保持小车静止，发送 CAL，记录至少 10 组 STATIC 数据。
3. 发送 STATE TILT，缓慢前倾和后仰，确认 Pitch 正负方向：前倾应为负，后仰应为正。
4. 发送 STATE SHAKE，做短时快速晃动，保存响应曲线。
5. 使用采集脚本：
   py -3 mpu6050_serial_capture.py --port COM7 --seconds 60 --state STATIC --mode ALL --rate 50
6. 使用绘图脚本：
   py -3 plot_mpu6050_curves.py 实验数据\MPU6050_STATIC_YYYYMMDD_HHMMSS.csv

七、烧录步骤
1. 本板通过 CH9102 的 USB 一键下载电路自动进入系统 Bootloader；“USB 一键下载”是板上的 USB 下载接口，不是一个按钮。
2. 执行：
   一键备份并烧录_MPU6050.bat
3. 脚本会先读取完整 256 KiB Flash 到 backup\B585_original_*.bin，再擦除、写入 Output\B585_MPU6050_Attitude.bin，并回读校验。
4. 校验成功后程序会跳转运行。若串口无输出，可轻按 RESET 后松开，等待约 5 秒。
5. RESET 是瞬时复位键，松开后程序会重新运行，不会保持复位状态。
