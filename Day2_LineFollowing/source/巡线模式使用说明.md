# 红外巡线模式使用说明（4路数字量寻迹模块）

本功能参考 `STM32F103RCT6_椭圆巡线例程_C10B` 与 `STM32F103RCT6_通用巡线例程_C10B`
两个 Keil 工程，将其 4 路红外寻迹算法移植到本平衡小车工程（HAL 库 Cube 版）。

## 涉及的改动

| 文件 | 说明 |
|---|---|
| `MiniBalance/HARDWARE/TrackModule/TrackModule.h/.c` | 新增：巡线模块驱动 + 寻迹状态机算法（与参考例程一致） |
| `MiniBalance/CONTROL/control.h` | 新增模式 `Track_Line_Patrol_Mode = 9` |
| `MiniBalance/CONTROL/control.c` | 5ms 中断调用巡线算法；速度环/转向环增加巡线分支；机械中值 |
| `MiniBalance_HARDWARE/KEY/key.c` | KEY1 单击模式循环中加入巡线模式（进入初始化、退出恢复引脚） |
| `MiniBalance/show/show.c` | OLED 首页在巡线模式显示：识别状态（第0行左）+ `IRDM` + DH1~DH4 四路灰度值（第0行右）；左右轮速/电压等原有内容保留 |

> `MDK-ARM/miniBlance.uvprojx` 未作任何改动（已还原为原始文件）。
> 新增的 `TrackModule.c` 需要**在 Keil 中手动引用**，见下文。

## 在 Keil 中手动引用 TrackModule.c（重要）

1. 用 Keil 打开 `MDK-ARM/miniBlance.uvprojx`；
2. 在左侧工程树中右键 **HAREWARE** 分组（或任意分组）→ **Add Existing Files to Group…**，
   选择 `MiniBalance_HARDWARE\TrackModule\TrackModule.c`（.h 不需要添加，头文件只作为
   包含路径使用）；
3. 菜单 **Options for Target** → **C/C++** 选项卡 → **Include Paths** 末尾追加：
   ```
   ..\MiniBalance_HARDWARE\TrackModule
   ```
4. 重新编译（Build）。编译通过后烧录即可，操作方式见下文。

## 硬件接线

巡线模块（4 路数字量红外寻迹模块）插到小车的**扩展接口**（与 PS2 无线手柄
接收机共用同一插座/引脚），**两者不能同时使用**：

| 模块信号 | 引脚 |
|---|---|
| DH1 | PC8 |
| DH2 | PC4 |
| DH3 | PC9 |
| DH4 | PB8 |

模块识别到黑线时对应引脚为高电平（1），算法按 4 位组合值（DH1~DH4 → 0~15）
查表决策：直行 / 左大弯 / 右大弯 / 左直角 / 右直角 / 十字 / 丢线等状态。

## 使用方法（上电自动进入 IRDM）

1. 小车上电后，程序默认进入 **IRDM（红外巡线）**，并自动把扩展接口配置为四路传感器输入；
2. 上电后的前约 **3 秒**用于 MPU6050 姿态稳定，期间电机保持停止；
3. 确认电机使能（KEY2）和电池电压正常，把小车放到黑线上，程序会自动开始巡线，
   不需要手机、PC 或 PS2 手柄持续操控；
4. IRDM 模式下 OLED 第 0 行显示：
   `STRAIGHT/L_90/R_90/L_BIG/R_BIG/L_SML/R_SML/CROSS/LOST`（当前识别状态）
   + `IRDM` + **DH1~DH4 四个布尔值**（1=压线）；第 3/4/5 行保留左右轮速、
   左右 PWM、电压等显示；把小车放到黑线上即可开始巡线；
5. 本项目版本固定使用 IRDM，KEY1 单击不会再切换到其它工作模式；PS2 读取在巡线模式下关闭，
   避免与四路传感器共用引脚；长按 KEY1 仍可切换调试显示界面。

> 提示：切换模式前建议先让小车保持静止平衡（放平扶稳），模式切换瞬间
> 速度/转向目标会跳变。

## 可调参数（在 `TrackModule.c` 顶部，全部为全局变量）

默认使用“通用巡线”参数，椭圆赛道的参数见注释：

| 参数 | 通用默认 | 椭圆例程 | 含义 |
|---|---|---|---|
| `Turn90Angle` | 80 | 80 | 直角弯转向差速 (mm/s) |
| `TurnMaxAngle` | 65 | 45 | 大弯道转向差速 |
| `TurnMidAngle` | 40 | 25 | 丢线时延续转向差速 |
| `TurnMinAngle` | 15 | 15 | 微调转向差速 |
| `BaseSpeed` | 500 | 400 | 直行基础速度 (mm/s)，当前项目约为原通用参数的 2 倍 |
| `ForwardLimit` | 50 | 80 | 转向差速超过该值则前进速度降为 0 |
| `Track_Turn_Scale` | 0.7 | 0.7 | 转向差速 → 转向环目标幅值的换算系数（本工程新增） |

- 速度环：巡线模式下 `Movement = base_speed_mm`（mm/s 换算为编码器单位，
  转弯时自动减速，与参考例程行为一致）；
- 转向环：`Turn_Target = turn_diff × Track_Turn_Scale`，转向时保留陀螺仪阻尼
  （Kd=Turn_Kd），方向右转为正。
- 机械中值：巡线模式 `Middle_angle = 0 + ANGLE_ZERO_OFFSET`（`control.c Select_Zhongzhi()`）。
  `ANGLE_ZERO_OFFSET`（见 control.h）是角度零点补偿——小车平衡（直立）姿态的读数
  应显示 0°，若不为 0 请按注释调整该宏；装模块后有平衡点偏移可按 CCD(-4)/ELE(-9)
  的经验在此调整。

## 常见问题

- **巡线乱走 / 走不了直线**：先看 OLED 上 DH1~DH4 是否随黑线位置正确变化
  （模块背面离地 1~2cm，黑线宽度 ≥ 1.5cm）；再检查 `Track_Turn_Scale`
  与各个转向角度参数是否合适（参考例程在两轮车上直接作用于差速，平衡车上
  经过转向环换算，实际效果以现场调试为准）。
- **上电后小车不动**：确认已等待约 3 秒、KEY2 已使能、
  `base_speed_mm>0`（直行状态）、电压正常；丢线状态下会维持上次转向，把车放回线上即可。
- **PS2 手柄不参与巡线**：当前项目固定为 IRDM 自动巡线，手机/PC/PS2 遥控指令
  不作为运动控制输入。
