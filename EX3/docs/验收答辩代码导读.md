# 实验三验收答辩代码导读

## 1. Keil 里先看哪个文件

本工程没有 `main.c`，主入口文件是：

`source/USER/MiniBalance.c`

里面的 `int main(void)` 就是程序入口。打开 Keil 后建议按这个顺序讲：

1. `USER/MiniBalance.c`：系统初始化和整体架构。
2. `MiniBalance/CONTROL/control.c`：角度环 PD、速度环 PI、PWM 输出、安全保护。
3. `SYSTEM/usart/usart.c`：串口调参命令、`printf` 重定向、`STATUS` 状态打印。
4. `MiniBalance/CONTROL/control.h`：控制层函数声明索引。

## 2. 本工程和厂商全功能代码的关系

准确说法：

本工程是基于 B585 参考工程做的“平衡控制验收精简版”。我们保留了能让小车站立的底层硬件驱动和控制主链路，删除了答辩不需要的外围功能，并加入了串口 ASCII 调参接口，用来完成实验三的级联 PID 调参展示。

不要说“完全从零写的”。更稳妥的说法是：

我们做的是二次整理、功能裁剪、串口调参接口设计和 PID 参数实验化。

## 3. 保留了什么

保留的都是平衡小车站立必须的模块：

- MPU6050 / DMP：获取姿态角和角速度。
- Kalman / 互补滤波：用于姿态解算对比。
- Encoder：获取左右轮速度反馈。
- Motor PWM：驱动左右电机。
- ADC：读取电池电压，低电压保护。
- EXTI：MPU6050 数据中断，作为控制周期入口。
- USART1：串口调参和状态打印。

## 4. 删除了什么

删除或不再使用的外围模块：

- 蓝牙 APP 协议。
- OLED 菜单显示。
- 超声波、遥控、雷达、CCD 等扩展模块。
- DataScope、show 等和本次验收无关的显示/通信代码。

删除这些模块的原因：

实验三只要求展示级联 PID 调参和小车稳定站立。保留太多外围模块会让代码结构复杂，也会让老师看不到 PID 主线。

## 5. 我们自己的改动重点

### 5.1 串口 ASCII 调参

位置：

`source/SYSTEM/usart/usart.c`

核心命令：

- `PID bk bd vk vi`：一次设置四个 PID 参数。
- `BAL kp kd`：只设置角度环。
- `VEL kp ki`：只设置速度环。
- `MID angle`：调整机械直立零点。
- `MODE DMP/KALMAN/COMP`：切换姿态解算方式。
- `ARM`：解除软件停机。
- `STOP`：立即停止 PWM。
- `STATUS`：打印当前参数和状态。

答辩口径：

为了展示控制变量调参，我们没有依赖厂商 APP，而是把调参命令改成普通串口文本命令。这样每一组实验的参数都能在串口助手里直接看到，也能和 Excel 表格对应。

### 5.2 级联 PID 主线清晰化

位置：

`source/MiniBalance/CONTROL/control.c`

角度环：

```c
balance = -Balance_Kp / 100 * Angle_bias - Gyro_bias * Balance_Kd / 100;
```

含义：

- `Balance_Kp`：车身偏离直立角越大，修正力越大。
- `Balance_Kd`：车身倒得越快，阻尼越强，抑制过冲和振荡。

速度环：

```c
velocity = -Encoder_bias * Velocity_Kp / 100 - Encoder_Integral * Velocity_Ki / 100;
```

含义：

- `Velocity_Kp`：抑制当前前后运动趋势。
- `Velocity_Ki`：消除长期慢慢漂移。

最终合成：

```c
Motor_Left = Balance_Pwm + Velocity_Pwm;
Motor_Right = Balance_Pwm + Velocity_Pwm;
```

本次只做直立，不做转向，所以左右轮输出相同。

### 5.3 8 组调参流程

最终演示参数：

```text
Balance_Kp = 27000
Balance_Kd = 110
Velocity_Kp = 400
Velocity_Ki = 2
```

参数在公式中会除以 100，所以等效为：

```text
Balance_Kp = 270.00
Balance_Kd = 1.10
Velocity_Kp = 4.00
Velocity_Ki = 0.02
```

调参顺序：

1. 只开角度环 P，逐步增加 `Balance_Kp`。
2. 固定 `Balance_Kp`，加入 `Balance_Kd`。
3. 角度环能抗倒后，再加入速度环 `Velocity_Kp`。
4. 最后加入很小的 `Velocity_Ki`，消除长期漂移。

## 6. 老师问“为什么这算你们自己的工作”时怎么答

可以这样说：

底层驱动和部分控制框架来自 B585 参考工程，因为这部分与硬件引脚、MPU6050、编码器和电机驱动强相关，直接重写风险高。我们的工作重点是把全功能工程裁剪成实验三需要的平衡控制版本，去掉蓝牙、OLED 和其他扩展模块；同时增加 USART1 文本调参命令、状态打印和 8 组控制变量调参流程。最终代码能在同一套控制结构下完成角度环 PD 与速度环 PI 的级联调参展示。

## 7. 一句话总结构架

MPU6050 负责感知车身姿态，编码器负责感知轮子速度，角度环 PD 让车“不倒”，速度环 PI 让车“不乱跑”，串口命令负责现场调参和状态展示。
