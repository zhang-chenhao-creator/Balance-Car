# 精简版源码改动说明

## 核心思路
本版本不是直接使用原厂全功能固件，而是以 B585 参考工程中已经验证过的硬件驱动和站立控制链路为基础，整理成“实验三验收精简版”。

本版本只保留平衡车站立必须的模块，并加入 USART1 ASCII 串口调参命令，使调参过程可以在串口助手里逐组展示。

答辩时建议表述为：

> 我们基于 B585 参考工程做了面向实验三的精简和重构：保留 MPU6050、编码器、电机 PWM、角度环和速度环，删除蓝牙、OLED、超声波等无关模块，并增加串口调参命令和 8 组控制变量调参流程。

## 关键代码位置
- `source/USER/MiniBalance.c`：主入口文件。工程没有 `main.c`，这里的 `int main(void)` 就是入口；只初始化 LED、KEY、电机 PWM、USART1、编码器、ADC、IIC、MPU6050、DMP、MPU 外部中断。
- `source/MiniBalance/CONTROL/control.c`：控制核心。MPU6050 中断中执行角度环 PD、速度环 PI、电机 PWM 输出、安全停机。
- `source/SYSTEM/usart/usart.c`：USART1 调参命令解析和 `printf` 重定向。只接收 ASCII 命令，不再使用蓝牙/APP/ROS 数据帧。
- `source/SYSTEM/sys/sys.h`：只包含平衡控制所需头文件。

## 删除模块
蓝牙 USART3、OLED、Lidar、Remote/超声波捕获、PSTWO、DataScope、show、ELE_CCD、蜂鸣器。

## 基准参数
当前最终演示参数：`Balance_Kp=27000`，`Balance_Kd=110`，`Velocity_Kp=400`，`Velocity_Ki=2`。

这些参数是串口命令和源码显示口径，控制公式中会除以 100：

- `Balance_Kp=27000` 等效 `270.00`
- `Balance_Kd=110` 等效 `1.10`
- `Velocity_Kp=400` 等效 `4.00`
- `Velocity_Ki=2` 等效 `0.02`

## 我们相对参考工程的工作

1. 精简工程结构：删除蓝牙、OLED、遥控、超声波、DataScope 等外围功能。
2. 保留平衡主链路：MPU6050 姿态、编码器速度、电机 PWM、ADC 电压保护。
3. 增加串口调参接口：支持 `PID`、`BAL`、`VEL`、`MID`、`MODE`、`ARM`、`STOP`、`STATUS`。
4. 调参过程实验化：把最终参数拆成 8 组控制变量实验，便于视频和答辩展示。
5. 注释补充：在 `MiniBalance.c`、`control.c`、`usart.c` 中补充主流程、控制公式、串口协议说明。
