# EX5 超声波安全监督测试流程

## 1. 软件验证

1. 用 GCC 编译并运行 `Tools/obstacle_guard_test.c`，必须输出 `All obstacle guard tests passed`。
2. 用 Keil 全量编译 `USER/MiniBalance.uvprojx`，必须为 0 Error、0 Warning。
3. 核对 `Firmware/` 中 HEX、BIN 和构建日志时间一致。

## 2. 串口与台架检查

> 下列硬件结果目前均为「待实车确认」。烧录前必须得到用户确认。

1. 烧录后连接 USART1，115200 8N1，发送 `STATUS`。
2. 确认存在 `DIST,UOK,OBS,UGUARD,USTATE,MISS,USTOP,USLOW,VREQ,VSAFE`。
3. 车轮悬空或可靠支撑，持续发送蓝牙前进命令，将平整障碍物逐步靠近：
   - `USTATE` 应按 `1(CLEAR) → 2(SLOW) → 3(BLOCKED)` 变化；
   - `BT` 可保持前进，但 `VSAFE` 应先下降，最后变为 0；
   - 障碍物未释放前不得恢复前进目标。
4. `BLOCKED` 时发送后退命令，确认负速度不被限制。
5. 移开障碍物，确认连续 3 个安全样本后才解除锁定。

## 3. 无回波与命令权限

1. 连续制造 3 次无有效回波，确认 `USTATE=4`、`VSAFE<=100`。
2. 恢复有效安全回波，确认第 2 个样本后退出降级。
3. 运行状态发送 `UOFF`，应返回 `ERR,UGUARD,STOP_REQUIRED`。
4. 发送 `STOP` 后执行 `UOFF`，应成功关闭；随后 `ARM` 应自动恢复 `UGUARD=1`。

## 4. 地面验收

使用垂直、平整、面积足够的障碍物，依次测试目标速度 100、300、600 mm/s：

- 分别在约 318、354、408 mm 进入减速区；实际阈值以 `USLOW` 为准。
- 不接触障碍物，停车后不持续向前爬行。
- 制动过程中保持平衡，不因过强反向动作跌倒。
- 若无法满足，只允许增大基础停车距离、反应时间或减速余量；没有实验数据前不得缩小安全参数。

每轮记录速度、开始减速距离、最终停车距离、是否接触、是否跌倒和 `STATUS`。结果写入 EX5 项目目录，不写入全局规则。
